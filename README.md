# Calculadora-HTML

Descrição: Calculadora web com funções de adição, subtração, divisão e multiplicação. Somente 2 números por cálculo, resultado pode ser reutilizado para o próximo cálculo. Resultados são guardados localmente via cache, e não em um servidor a parte. Um integrante ficaria com a parte gráfica, enquanto outro ficaria com a parte logica.

Issues:
1.	UI do site (botões numéricos, botão de limpar, visor)
2.	Operações Matemáticas (adição, subtração, divisão e multiplicação)
3.	Suporte de teclado
4.	Salvar as operações localmente dentro de um array

Pré-requisitos: HTML5 Boilerplate, CSS
